# A uuid that is not installed is skipped by GNOME Shell without an error (the .debs rely on the same thing for Debian).

# This is the Fedora/Arch counterpart of release/native/session/ubuntu-session-extensions.txt, with the upstream uuids:
#   appindicatorsupport@rgcjonas.gmail.com  tray icons. Packaged as gnome-shell-extension-appindicator (Fedora and Arch).
#   tiling-assistant@leleat-on-github       window tiling: Vitre's snapping motion uses its Super+Left/Right keys. Not in the Fedora or Arch
#                                           repositories (checked 2026-10-22); installed from extensions.gnome.org it is picked up here.
# Left out, because they are Ubuntu's: ubuntu-dock, ding (desktop icons), myna-shell, snapd-prompting, snapd-search-provider,
